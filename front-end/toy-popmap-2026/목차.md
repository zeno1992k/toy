## 목표와 진행 방식

[기획.md](기획.md)의 새로운 서비스 **서울 문화 산책 플래너**를 사용자가 직접 구현한다. 강의 전반의 기술을 [강의연계.md](강의연계.md)에 연결하고, 설명을 듣는 데서 끝나지 않도록 각 주제에 코드 작성과 확인 과제를 둔다.

기능 단원의 흐름은 **강의 원리 읽기 → 새 서비스 요구사항 설계 → 작은 손코딩 → 동작 확인 → 원본과 비교·개선 → 기록**이다. AI는 관련 소스와 노트를 실제로 읽어 설명하고, 디자인·기능 설계와 단계별 힌트·리뷰를 제공한다.

비슷한 역할의 기술도 동일한 요구사항을 직접 구현해 비교한다. 현재 단계의 목표는 한 번에 하나씩 익히는 것이며, 모든 도구를 한꺼번에 설치하는 것으로 학습 완료를 대신하지 않는다.
