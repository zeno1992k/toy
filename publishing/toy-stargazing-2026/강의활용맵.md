기준일: 2026-10-03(토)
목적: **원본 소스의 원리를 폭넓게 직접 학습하고, 새 별 관측 포트폴리오로 재구성한다.**

## 사용자의 의도와 진행 원칙

강의 이미지·문구·화면을 그대로 재사용하는 요청이 아니다. 원본의 코드·구조·계산·상태 관리·애니메이션·도구를 적극적으로 읽고 실험해, 사용자가 새 콘셉트로 직접 구현하는 과정이다.

- 원본 예제 전체를 목록으로 추적한다. 완성본뿐 아니라 중간 Clip, started/finished 차이, 런타임 분기, 주석의 대안 구현과 보조 자료도 확인한다.
- 매 단위는 **원본 읽기 → 핵심 원리 직접 실습 → 값·조건 변형 → 새 사이트 기능에 적용 → 리뷰**로 진행한다.
- `목차.md`의 52개 기본 단위에 아래 원본별 과제를 편입한다. 52라는 숫자는 전체 학습의 상한이 아니다.
- React·Next·물리·모델·고급 갤러리도 추가 학습 단위로 추적한다. 명칭만 보너스로 붙여 학습에서 빠지게 두지 않는다.
- 원본에 없는 자체 확장과 원본의 실제 구현을 구분한다.
- 사용자 코드를 AI가 먼저 완성하지 않는다. 단계마다 읽을 파일·함수·코드 구간과 작은 과제를 제시한다.

## 상태를 기록하는 방법

각 항목은 `자료 확인 / 원본 읽기 / 직접 실습 / 사이트 적용 / 리뷰`를 별도로 기록한다. **현재 사용자의 구현·실습·리뷰 완료 항목은 없다.** 아래 표의 확인은 자료 조사 상태이며 학습 완료가 아니다.

- 코드 확인: 원본의 대표 실행 코드·스타일·셰이더를 읽었다.
- 목록 확인: 파일·페이지·도식 구성만 확인했다.
- 미확인: 실제 내용이나 자료를 아직 확보하지 못했다.
- PDF 텍스트가 깨지거나 바이너리 디자인인 경우 시각 확인이 필요한 상태를 남긴다.
